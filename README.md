# 🎓 Student Management System

A Student Management System built in C++ to manage student records efficiently. This project demonstrates the implementation of Object-Oriented Programming (OOP) concepts and file handling to perform various operations on student data.

## ✨ Features
- ➕ Add Student Records
- 📋 View All Students
- 🔍 Search Student by ID
- ✏️ Update Student Information
- ❌ Delete Student Records
- 💾 Store Data Using File Handling
- 🖥️ Menu-Driven Interface
- ⚡ Fast and Efficient Operations

## 🛠️ Technologies Used
- C++
- Object-Oriented Programming (OOP)
- File Handling
- Standard Template Library (STL)

## 🚀 Getting Started

### Prerequisites
- C++ Compiler (GCC/MinGW)
- Visual Studio Code or any C++ IDE

### Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/Student-Management-System.git
```

2. Navigate to the project directory:
```bash
cd Student-Management-System
```

3. Compile the source code:
```bash
g++ main.cpp -o student_management
```

4. Run the program:
```bash
./student_management
```
For Windows:
```bash
student_management.exe
```
